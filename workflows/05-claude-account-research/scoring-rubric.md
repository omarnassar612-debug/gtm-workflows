# Scoring rubric

The research workflow scores each account. The rubric below is a template. Set the factors and weights for your own offer before running a batch.

| Factor | Question | Points |
|---|---|---|
| Signal strength | Is the signal current and verifiable (live ad, open job post)? | |
| Fit | Is the company the right size and trade for the offer? | |
| Reachability | Is there a published contact for the right role? | |
| Timing | Is there a reason to act now (active campaign, open role)? | |

Define the points, the threshold for "worth contacting", and what happens below it.
